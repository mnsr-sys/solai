# Data sources and provenance

No external geospatial dataset is bundled in this initial repository. Add datasets only after checking access terms, attribution, resolution, date and suitability for the assessment.

Potential source families to evaluate:
- Satellite imagery and land cover: Sentinel-2, Landsat, ESA WorldCover.
- Elevation and terrain: Copernicus DEM or SRTM.
- Solar resource: NASA POWER or PVGIS.
- Flood exposure: authoritative state/national flood layers and documented hydrology sources.
- Substations and network: utility-provided coordinates, asset register and network data.
- Emission factors: applicable, published grid emission-factor source with version and reporting year.

For each ingested layer record: publisher, dataset name, URL or identifier, licence, retrieval date, vintage, spatial resolution, CRS, processing steps and any known limitations.

Do not use synthetic utility-network records without a visible synthetic-data label.
